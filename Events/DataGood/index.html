What is DataGood?

What is DataGood?

DataGood is a 4-session training program focused on four different tools:

  • Power BI — Data Analysis & Interactive Dashboards
  • KNIME — Data Science & Visual Workflows
  • Looker Studio — Data Visualization & Interactive Reports
  • Orange Data Mining — Machine Learning & Data Mining

Together, these sessions provide an introduction to several important parts of the modern data workflow: analyzing data, transforming it, visualizing it, building workflows, and experimenting with machine learning.

The tools were chosen specifically to give beginners exposure to different approaches to working with data — from business intelligence and dashboards to visual data science and machine learning.

The goal is simple:

  • Learn the tools.
  • Work with real data.
  • Build practical skills.

The Program

The Four Sessions

Each Saturday introduces one tool, from dashboards to machine learning.

Session 01

Power BI

Data Analysis & Interactive Dashboards

The first session introduces participants to Power BI and the fundamentals of turning raw data into useful visual information. The session focuses mainly on data visualization, including:

  • Column & Bar Charts
  • Line & Area Charts
  • Common Charts
  • Map Charts
  • Uncommon Charts
  • Tables
  • Cards
  • Slicers
  • Buttons & Bookmarks
  • Interactive dashboards

The objective is to help participants understand how data can be transformed into clear, interactive dashboards that communicate insights effectively. Power BI is particularly useful for business intelligence and reporting, making it a valuable tool for students interested in data analysis.

Session 02

KNIME

Data Science & Visual Workflows

The second session introduces KNIME, a visual, low-code/no-code platform for building data workflows. KNIME allows users to connect different operations together visually, making it possible to work with data without having to write large amounts of code.

Participants will discover concepts such as:

  • Data preparation
  • Data transformation
  • Visual workflows
  • Data exploration
  • Connecting different operations
  • Introduction to machine learning
  • Building practical data workflows

The goal is to show participants that data science doesn't always have to start with hundreds of lines of code.

Session 03

Looker Studio

Data Visualization & Interactive Reports

The third session focuses on Looker Studio, a web-based reporting and visualization tool. Participants will learn how to work with data sources and turn them into interactive reports and dashboards.

The session covers ideas such as:

  • Connecting data
  • Creating visualizations
  • Designing reports
  • Interactive charts
  • Filters and controls
  • Presenting insights
  • Sharing reports

Looker Studio is designed around creating shareable, customizable reports and dashboards, making it a useful tool for communicating information visually.

Note: Google changed the product's name back to Data Studio in April 2026, although many people still know it as Looker Studio.

Session 04

Orange Data Mining

Machine Learning & Data Mining

The final session introduces Orange Data Mining, a visual programming platform for data mining, machine learning, and data visualization. Orange uses a visual workflow approach where users place widgets on a canvas and connect them together to create data-processing and machine-learning workflows — all without writing code.

Participants will explore:

  • Data preparation
  • Data exploration
  • Data visualization
  • Building machine-learning workflows
  • Training models
  • Comparing models
  • Model evaluation

This session provides a beginner-friendly introduction to the machine-learning workflow, allowing participants to understand the different stages involved in going from a dataset to a trained model.

For Beginners

Is DataGood for Beginners?

Yes. DataGood was designed with beginners in mind. You don't need to already be a data scientist or machine-learning engineer to participate.

The main prerequisite is simply:

An interest in data.

Having a laptop is also recommended because participants can follow along and practice during the sessions.

The idea is not to expect participants to already know everything — the bootcamp is designed to help them discover these tools step by step.

Outcomes

What Participants Can Get From DataGood

By the end of the bootcamp, participants should have:

  • An introduction to several popular data tools
  • A better understanding of the data workflow
  • Experience creating visualizations and dashboards
  • Experience working with visual data workflows
  • An introduction to machine-learning workflows
  • Practical exposure to no-code/low-code approaches
  • A better understanding of which data tools might fit their future projects
  • A foundation for continuing their learning in Data Science, Business Intelligence, and AI

Most importantly, participants leave with hands-on exposure rather than only theoretical knowledge.
